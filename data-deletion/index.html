Data deletion

Use this page to ask Roleflow to delete Instagram and account data, or to check a confirmation code from Meta.

Ask Roleflow directly

Email diego@roleflow.io from the address on the account. Say whether to delete one business workspace, disconnect Instagram, or delete the login. We delete the message threads we store, the encrypted Instagram or Google token for that workspace, and uploaded voice notes when the request covers them. Records a customer entered as closed revenue can be removed with the workspace.

Meta callback

Instagram’s data-deletion callback for the Roleflow Meta app is:

https://xrsipofgofvjiskmsgij.supabase.co/functions/v1/roleflow-acquisition/deletion

Meta sends a signed request. Roleflow checks the signature, deletes threads and messages for that Instagram user id, and disconnects the account when the id is the connected professional profile. The response includes a confirmation code and a link back to this page.
